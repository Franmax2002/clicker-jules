# Cookie Clicker Web Application

A simple, responsive web application featuring a centered interactive cookie graphic and a click counter that persists your progress.

## Project Structure

- `index.html`: Contains the HTML structure, SVG cookie graphic, and CSS styling.
- `script.js`: Contains JavaScript counter logic, event handling, floating text animations, and cookie storage helpers (`document.cookie`).
- `README.md`: Project documentation and user guide.

## Features

- **Interactive Cookie:** A centered SVG cookie with hover and click animations.
- **Click Counter:** Tracks how many times the cookie has been clicked.
- **Floating +1 Animation:** Visual feedback on each click.
- **Cookie Persistence:** Uses browser HTTP cookies (`document.cookie`) so your click count is saved across page reloads.
- **Reset Button:** Allows you to reset the counter back to zero anytime.
- **Responsive & Accessible Design:** Works smoothly across devices and supports keyboard navigation (Enter / Space to click).

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Click the cookie and watch your count grow!
